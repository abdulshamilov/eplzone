# Своя подача

Прототип сервиса, который собирает кофе под пожелание гостя: вкус, цвет, подачу
и рисунок на пенке. Три статические страницы, никакой сборки и бэкенда.

| Файл | Что это | Адрес после публикации |
|---|---|---|
| `index.html` | Прототип приложения: генерация напитка, выбор подачи, редактируемый состав, 3D-стакан | `/eplzone/podacha/` |
| `launch.html` | Презентация: как устроена система, сколько стоят запросы к модели, порядок работ. В конце QR на прототип | `/eplzone/podacha/launch.html` |
| `brief.html` | Маркетинг-бриф: аудитории, отстройка, экономика заказа, метрики пилота | `/eplzone/podacha/brief.html` |

## Как включить GitHub Pages

Settings → Pages → Build and deployment → Source: **Deploy from a branch**,
ветка `claude/nifty-hypatia-91h50v` (или `main` после слияния), папка `/ (root)`.

Через минуту страницы открываются по адресам из таблицы выше.
QR-код в презентации ведёт на `https://abdulshamilov.github.io/eplzone/podacha/`
и заработает сразу после включения Pages.

## Зависимости

Только three.js r128 с cdnjs для трёхмерного стакана. Всё остальное — свой код.
Если WebGL недоступен, страница показывает заглушку, а состав, фильтр цены
и расчёты продолжают работать.
